    rationale: Clearing this fact lets the model invent an Operation whose caller's role is not present in the permission matrix for that operation kind.     expected to FAIL: LeastPrivilege, FR_015_OnlyStaffDecides
      - LeastPrivilege: FAIL (expected)
      - FR_015_OnlyStaffDecides: FAIL (expected)

  - MUTATE F_OnePendingPerCustomer  → runs/A-L1/mutated_F_OnePendingPerCustomer.als
    rationale: Clearing this fact removes the partial-unique constraint, allowing two simultaneous Pending Review applications for the same customer, which is exactly the FR-005 bug.
    expected to FAIL: FR_005_OnePendingPerCustomer
      - FR_005_OnePendingPerCustomer: FAIL (expected)

  - MUTATE F_OneSubmittedEventPerApp  → runs/A-L1/mutated_F_OneSubmittedEventPerApp.als
    rationale: Clearing this fact lets an application exist without (or with multiple) submitted audit events. The injection picks an application with zero submitted events, falsifying the 'one submitted event per application' clause in all three assertions.
    expected to FAIL: AuditCompleteness, FR_016_AuditTrail, AppendOnly
      - AuditCompleteness: FAIL (expected)
      - FR_016_AuditTrail: FAIL (expected)
      - AppendOnly: FAIL (expected)

  - MUTATE F_OwnershipBasedAccess  → runs/A-L1/mutated_F_OwnershipBasedAccess.als
    rationale: Clearing this fact removes the ownership-conditional gate. The injection forces a customer to view another customer's application via GetApplicationById, which is the FR-013 information-leakage scenario.
    expected to FAIL: OwnershipBasedAccess, FR_013_CustomerOwnAccess
      - OwnershipBasedAccess: FAIL (expected)
      - FR_013_CustomerOwnAccess: FAIL (expected)

  - MUTATE F_SubmittedEventAttribution  → runs/A-L1/mutated_F_SubmittedEventAttribution.als
    rationale: Clearing this fact lets a submitted audit event record an actor other than the application's customer. The injection forces exactly such a misattribution, which AttributionCorrectness should catch.
    expected to FAIL: AttributionCorrectness
      - AttributionCorrectness: FAIL (expected)
